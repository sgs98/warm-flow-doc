# 设计器双模式

::: tip
- Warm-Flow 设计器原生支持**经典模型**和**仿钉钉模型**两种设计器模型，同一套流程定义可以在两种模型之间相互转换
- 模型只决定设计器的<span class="wf-em">布局与展示方式</span>，不影响流程定义的节点、跳转、条件等业务语义
- 新建流程时选择模型，已有流程可在画布内用工具栏的「切换」按钮转换，保存后生效
:::

## 1. 两种模型的区别

| 维度 | 经典模型（CLASSICS）                        | 仿钉钉模型（MIMIC）                                  |
| ---- | ------------------------------------------- | ---------------------------------------------------- |
| 布局 | 自由布局，节点坐标可任意拖动                | 上下结构布局，按流程层级自上而下排列                 |
| 形态 | 圆形 / 矩形 / 菱形（开始、中间、网关、结束） | 类钉钉审批卡片，卡片内展示节点名称、办理人、协作方式 |
| 连线 | 自由连接，可任意调整节点位置                | 由引擎按上下结构自动路由，分支与网关自动配对         |
| 场景 | 复杂流程、需要精确摆放节点位置              | 审批类流程，希望开箱即用的类钉钉观感                 |

模型保存在 `flow_definition.model_value` 字段（`CLASSICS` / `MIMIC`），详见[表结构](table.md)。

## 2. 选择设计器模型

- 新建流程：在「基础信息 → 设计器模型」中选择**经典模型**或**仿钉钉模型**
- 流程保存后该选项不可修改（页面提示：切换后重置节点，保存后不支持修改）
- 移动端不支持选择模型，新增流程默认使用仿钉钉模型
- 需要更换已有流程的模型时，使用画布内的模型切换（见下一节）

## 3. 画布内切换模型

流程设计页签工具栏中的「切换」按钮，可在经典模型与仿钉钉模型之间转换：

- **经典 → 仿钉钉**：按上下结构<span class="wf-em">自动重排</span>节点布局，按流程层级分层、分支按间距展开、网关分支自动配对
- **仿钉钉 → 经典**：<span class="wf-em">保留当前坐标</span>切换为自由布局，不再重排

::: warning 注意
- 切换只是画布内的预览，点击保存后才会把新的模型与坐标写入流程定义
- 未保存时刷新页面即可还原
- 嵌入模式（`onlyDesignShow=true`）同样支持切换，保存时只回写设计器模型与节点坐标等最小信息
:::

## 4. 转换时自动完成的工作

不论从哪个方向转换，引擎都会按目标模型的节点尺寸重新计算画布，保证转换后图形自洽：

1. 转换前先同步画布最新数据，本次新增的节点、连线与拖动后的坐标都会参与转换，不会被丢弃
2. 按目标模型的节点尺寸重建连线折点（仿钉钉卡片宽 260、经典节点宽 100，直接沿用旧折点会让连线脱开节点）
3. 按新布局重算连线标签坐标，避免标签压住节点或落到其它连线上
4. 清理另一个模型残留的节点尺寸，避免仿钉钉卡片尺寸（260×76）带到经典模式
5. 回正网关节点标签，经典模式下网关标签位于菱形下方，不再压住菱形
6. 重置撤销基准：转换本身不可撤销，转换后点「上一步」不会退回半转换状态，转换后的编辑仍可正常撤销与重做

::: tip 说明
- 重建连线需要流程中存在<span class="wf-em">开始节点</span>，引擎会从开始节点出发按跳转关系重建全部连线；缺少开始节点时只切换模型，不重建连线
- 转换不会改变节点编码（nodeCode）与流程定义 id，连线折点由引擎按目标模型重新生成
:::

## 5. 与运行态的关系

- 设计态：节点按设计器模型渲染，并回显节点的办理人
- 运行态：与设计器模型无关，节点和连线按[流程图渲染规则](chart_manage.md#_6-流程图渲染规则)着色，未完成节点不展示办理人
- 流程状态三原色配置与模型相关（公共模型 / 经典模型 / 仿钉钉模型），详见[流程图管理](chart_manage.md)
