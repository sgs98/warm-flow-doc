# [Dromara Warm-Flow工作流](https://gitee.com/sgs98/warm-flow)
 

## 本地测试

### 第一次安装

- 安装 [NodeJS 20](https://nodejs.org/en/download/)
- 使用 [GitHub Desktop](https://desktop.github.com/) 或者 Git 命令行来克隆本库 (`git clone`)
- 在**项目根目录**运行 `pnpm i` 命令

### 本地测试

- 在**项目根目录**运行 `pnpm docs:dev` 命令
  - 站点会默认运行在 `http://localhost:8081` 

### 打包
-  `pnpm docs:build` 命令
